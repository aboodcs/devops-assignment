# 1. RAID (Redundant Array of Independent Disks)

RAID is a technology that combines multiple disks to improve **performance data protection or both**

Common types:

* **RAID 0:** Improves performance but has no redundancy

* **RAID 1:** Mirrors data between two disks for redundancy

* **RAID 5:** Uses distributed parity and can survive one disk failure

* **RAID 10:** Combines mirroring and striping for performance and redundancy

# 2. DevOps

DevOps is a way of working that combines **development and operations** to deliver applications faster and more reliably

It uses automation and tools for:

* Development

* Testing

* Deployment

* Monitoring

* Infrastructure

Examples: **Git Docker Kubernetes Jenkins GitHub Actions Terraform**

# 3. High Availability (HA) and Disaster Recovery (DR)

### High Availability (HA)

HA means keeping an application or service **available with minimal downtime** when a server or component fails

Technologies that can be used:

* Load Balancer

* Replication

* Clustering

* Failover

Examples:

**Oracle:** RAC

**PostgreSQL:** Streaming Replication

**Tomcat:** Multiple Tomcat servers behind a Load Balancer

### Disaster Recovery (DR)

DR is the process of **recovering systems and data after a major failure or disaster**

Technologies that can be used:

* Backups

* Replication

* Standby servers

* Cloud disaster recovery

Examples:

**Oracle:** Data Guard

**PostgreSQL:** Streaming Replication / Standby Server

**Tomcat:** Backup and restore

# 4. Cloud Computing

Cloud computing means using **IT resources like servers and storage over the internet** instead of managing your own physical servers

### Cloud Vendor Types

Examples of cloud providers:

* AWS

* Microsoft Azure

* Google Cloud

* Oracle Cloud

### IaaS

**Infrastructure as a Service**

Provides infrastructure such as:

* Virtual Machines

* Storage

* Networking

### PaaS

**Platform as a Service**

Provides a platform where developers can deploy applications without managing the underlying infrastructure

### SaaS

**Software as a Service**

Provides a complete software application that users can use directly

### Main Difference

**IaaS → You manage more**

**PaaS → Provider manages the infrastructure**

**SaaS → Provider manages almost everything**

# 5. DNS and Load Balancers

### DNS

DNS stands for **Domain Name System**

It converts domain names into IP addresses

### Load Balancer

A Load Balancer distributes incoming traffic across multiple servers

This helps improve **availability performance and reliability**
