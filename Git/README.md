### 1. Create your own project on GitHub or GitLab

I created my own project on GitHub:

https://github.com/aboodcs/devops-assignment

### 2. Use the command line to upload and download files in the project directory

I used these commands to upload my files to GitHub

```bash
git init

git add .

git commit -m "add assignment files"

git remote add origin https://github.com/aboodcs/devops-assignment.git

git branch -M main

git remote set-url origin https://github.com/aboodcs/devops-assignment.git

git push -u origin main
```
